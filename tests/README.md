# SDUcraft 安装任务回归

## 固定开启版本隔离

```powershell
.\tests\Run-SduIsolationTests.ps1
```

使用 Windows 自带的 .NET Framework VB 编译器，原样提取生产 `McInstance.PathIndie` 属性，验证五种旧全局策略与实例关闭设置均不能改变隔离目录、旧设置迁移和重复读取不反复写入、新实例相互独立、设置保存失败仍保持隔离，以及原有公共 mods 与存档保持不变。Settings 使用内存宿主，文件仅写入 `tests/bin` 下的独立目录，不操作注册表或真实游戏目录。Actions 在 Debug、Release 中均运行该测试。

## 皮肤站唯一登录入口

```powershell
.\tests\Run-SduSkinLoginTests.ps1
```

编译生产 `SduSkinLogin.vb`，并原样提取当前登录数据模型、输入路由、校验及实例选择属性，执行 14 项回归：首次使用默认皮肤站、其他站点的凭据清理、旧登录模式迁移、同站账号与令牌保留、重复刷新不反复写设置、拒绝旧登录类型和非指定认证地址、当前表单/缓存账号路由，以及切换实例不恢复其他站点。设置存储、界面输入与日志采用测试宿主；不读写用户注册表、不使用真实账号、不发送网络请求。

## 启动时官网连通性检查

```powershell
.\tests\Run-SduNetworkCheckTests.ps1
```

直接编译生产 `SduNetworkCheck.vb`，用替代 HTTP 传输层验证：检查目标固定为 HTTPS 官网、HTTP 成功/重定向/403/503 均视为连通、首次连接失败后重试、持续失败与超时最多尝试两次、仅读取响应头并释放响应、后台启动且每进程仅检查一次、离线提示校园网、在线不弹窗、程序异常不误报网络故障。线程调度、日志与弹窗由计数宿主替代，不发送真实网络请求。Actions 在 Debug、Release 中均运行该测试。

在 Windows、.NET Framework 4.x 运行时和 .NET 8 SDK 环境执行：

```powershell
.\tests\Run-SduLoaderBridgeTests.ps1
```

脚本编译生产代码 `SduLoaderBridge.vb`，并从当前 `ModLoader.vb` 原样提取 `LoaderBase`、`LoaderTask`、`LoaderCombo`，使用实际的任务线程、父子调度、状态和取消机制运行测试。UI 调度、日志、未使用的下载器等宿主能力使用替代实现；不连接官网，不下载整合包，不操作游戏目录。

覆盖 13 项：父任务等待子安装、进度传递、原始失败传播、需要手动安装时保留失败状态和原因、父取消子任务、子取消父任务、已完成/失败任务不被重启、等待线程中断时取消子任务，以及拒绝等待未启动任务。另原样提取生产 `McInstallState` 的两个重载，分别检查加载、成功、失败、取消状态：SDU 子任务不重复提示，默认安装仍保留通知；关闭通知不会跳过目录清理与版本列表刷新。清理与刷新在此使用计数宿主，不操作游戏目录。

测试输出保存在被 Git 忽略的 `tests/bin`。这些测试不代替真实整合包安装与 WPF 界面回归。

## 裸客户端的文件布局与 mods 更新

```powershell
.\tests\Run-SduBareClientTests.ps1
```

直接编译生产 `SduBareClientInstaller.vb` 和 `SduPackageFiles.vb`，创建真实的临时 ZIP、文件及实例目录，覆盖 26 项：隔离布局、网站实例名、同名数据保护、损坏 JSON、取消、线程中断、公共缓存冲突、路径校验、重复文件、配置优先级、隔离设置校验、项目 ID 定位，以及“仅同步 mods + 完整旧目录备份”。更新测试逐字节比较配置、存档、截图、资源包、游戏 JSON/JAR 和 PCL 设置，确保它们不变。故障注入测试在实际目录移动中模拟发布失败与恢复失败，检查旧模组恢复或保留在可找回的备份中。包文件回归检查根目录/一级目录、大小写、反斜杠条目的实际读取，以及 zip/mrpack 连续导出的正确后缀、新包内容和旧包保留。

PCL 的 INI 写入由宿主回调提供，测试回调使用相同的冒号格式；生产安装器会重新读取磁盘，确认隔离设置已写入才发布实例。测试不覆盖真实整合包下载、Minecraft 启动、WPF UI 和断电恢复。

GitHub Actions 的 Debug、Release 任务均运行上述安装测试。

## 主页嵌套滚动的事件路由

```powershell
.\tests\Run-SduScrollTests.ps1
```

编译生产 `MyScrollViewer.vb`，加载 `Application.xaml` 的真实滚动条模板，在 .NET Framework WPF 的 STA 线程上执行鼠标滚轮的隧道和冒泡事件。验证：普通/自定义内层列表优先滚动、内层上下边界交给外层、页面内容滚动、外层无溢出时内层仍可滚动、多行文本框保留滚轮、Run 文本来源的路由，以及零滚轮增量。

另外编译完整生产首页面板及数据模型，覆盖 4 组回归：连续触底按 5→8→11→…→29 展开、嵌套页面内连续滚轮加载全部、强制刷新更新数据并合并加载期间的重复请求、刷新失败后恢复且错误卡片不重复。首次布局不会自动展开后续页。

动画调度、主窗口、卡片外壳、网络及安装服务使用替代实现；控件、尺寸计算、视觉/逻辑树与滚轮处理来自真实 WPF 和生产代码。网络宿主返回固定 JSON；此测试不启动完整游戏客户端，也不下载文件。Actions 同样运行这组回归。
